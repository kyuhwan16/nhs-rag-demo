NHS Navigation RAG Agent

A retrieval-augmented prototype helping international students navigate NHS GP registration, referrals, NHS 111, the Immigration Health Surcharge, and emergency vs urgent care. Every answer is grounded in one of the 5 source documents below and shown with its retrieval score.

How this works (retrieval pipeline)
  1. Retrieval: the question and all 5 NHS documents are converted into TF‑IDF vectors (word‑importance scores), computed in JavaScript in this page — no external API.
  2. Ranking: cosine similarity between the question vector and each document vector picks the single best‑matching document.
  3. Extractive answer: within that document, the same TF‑IDF + cosine similarity method scores individual sentences, and the top sentence(s) are returned verbatim — nothing is paraphrased or invented.
  4. Explainability: the source filename and similarity score are always shown, so every answer is traceable back to its document.
  5. Out‑of‑scope handling: if the best score is below a threshold (0.05), the system reports "no relevant document found" instead of guessing.
Prototype for academic demonstration only — not a substitute for real NHS advice. Sources: NHS.uk and UKCISA guidance, summarised for this project.
